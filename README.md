# TRACE

The academic website of the Team for Research on Atmospheric Chemistry & Environment (TRACE). The site uses HTML and CSS and requires no build step.

| Page | File |
| --- | --- |
| Home | `index.html` |
| Research | `research/index.html` |
| Publication | `publication/index.html` |
| Principal Investigator | `people/principal-investigator/index.html` |
| Faculty | `people/faculty/index.html` |
| Team Member | `people/team-member/index.html` |
| Alumni | `people/alumni/index.html` |

Edit the corresponding page to add project descriptions, citations, or profiles. Shared styles are in `assets/site.css`. The publishing source is the root of the `main` branch.
